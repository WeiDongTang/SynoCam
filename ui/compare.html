OPTION A · ✅ 已定稿

Aurora · 浅色原生

iOS 系统蓝 + 大留白 + 分组白卡片，最贴近 Apple 原生 App 的干净高端。
浅色 / 克制 / 消费者友好
  • 浅灰底 + 纯白卡片，柔和阴影，圆角 14–16px
  • 大标题导航（Large Title）+ 分段控制器
  • 主色 iOS 蓝，状态色绿 / 红 / 琥珀
  • 信息密度低、留白充足，观感最轻松
取舍：最容易被接受、最"高端消费品"，但专业监控感和信息密度最弱。

OPTION B

Slate Command · 专业仪表盘

冷蓝灰 + 直角几何 + 系统遥测条，专业 NVR / 安防工作台的精密感。
深色 / 精密 / 信息密集
  • 顶部遥测条：在线路数 / 码率 / CPU / 运行时长
  • CH 通道号 + OSD 时间戳叠在画面上
  • 等宽字体、细边框、表格化事件日志
  • 信息密度最高，运维视角最专业
取舍：专业感与真实感最强，但偏"工具"，普通家庭用户可能觉得冷硬。

OPTION C

Editorial · 暖白编辑风

象牙纸 + 衬线大标题 + 细线分区 + 一点朱红，杂志式的设计驱动美学。
暖白 / 排版 / 有格调
  • 衬线字体大标题 + 编号 + 细线分区，无卡片阴影
  • 画面像摄影作品，带图注与通道编号
  • 朱红仅用于录制标记 / 当前项，极克制
  • 完全不像传统监控软件，辨识度最高
取舍：最有设计格调、最不像"AI 做的"，但偏离安防工具惯性，需确认能接受。
